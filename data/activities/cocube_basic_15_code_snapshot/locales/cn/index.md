### 代码快照

如果想把程序长期保存在 CoCube 机器人上，并在下次使用时快速打开，可以使用 MicroBlocks 的“代码快照”功能。

代码快照会把当前代码保存到 CoCube 的文件系统中。保存成功后，即使断开 MicroBlocks IDE，也可以通过机器人上的目录系统直接运行这些程序。

#### 1. 准备工作：更新 CoCube 机器人固件

使用代码快照前，请先确认 CoCube 是否已经支持该功能。

在 CoCube 未连接 MicroBlocks IDE 的情况下，按住 B 按键，同时连续按 4 次 A 按键。如果 CoCube 屏幕出现变化，并且可以通过 A/B 按键切换目录，说明当前固件已经支持代码快照，无需升级。

如果没有出现目录，请使用数据线连接 CoCube 机器人，在 MicroBlocks IDE 中依次点击“设置”->“升级主板固件”，选择“CoCube”，再选择对应的端口号。

![upgrade1](upgrade_1.png)
![upgrade2](upgrade_2.png)

固件升级大约需要 1 分钟。升级过程中，请保持 MicroBlocks IDE 页面处于浏览器前台，不要进行其他操作，否则可能导致升级失败。如果升级失败，请重新升级一次。

#### 2. 打开目录系统

升级完成后，CoCube 固件中会自带近 10 个代码快照。可以先通过目录系统体验这些内置程序。

在 CoCube 未连接 MicroBlocks IDE 的情况下，按住 B 按键，同时连续按 4 次 A 按键。等 CoCube 屏幕出现主页后，再按 A 或 B 按键进入代码快照目录。进入目录后，按 A 或 B 按键移动光标；同时按下 A/B 按键，即可运行当前选中的代码快照。

- guide：显示当前 CoCube 机器人的 BLE ID，并介绍 CoCube 机器人系统的各个部分。

- bird：Hoppy Bunny 版本的 Flappy Bird 游戏。用按键控制小兔子穿过管道，看看你能拿到多少分。

- buzzer：使用蜂鸣器弹奏音乐的程序。将 CoCube 放在音乐地图的不同琴键上，机器人会通过蜂鸣器发出对应音调。

- camera：配合 Sengo2 摄像头使用的测试程序。CoCube 可以识别交通卡片，并执行对应动作。

- face：使用屏幕模拟表情的程序。按下 A/B 按键后，可以切换表情颜色。

- football：机器人踢足球程序。拿出足球场地图，在地图上摆放几个 3D 打印足球；给 CoCube 安装夹爪模块后，让 CoCube 紧贴足球并面朝右侧球门中央，按下 A 键记录当前位置。对每个足球重复这一操作，全部记录完成后按下 B 键，机器人会自动找到这些足球的位置并完成射门动作。

- maze：机器人走迷宫程序。操作方式与 football 程序类似。拿出迷宫地图或赛车地图，将机器人放在地图上，在每一个拐点位置按下 A 键记录；然后把机器人放到路径起点，按下 B 按键，机器人会沿着记录的轨迹自主移动。

- midi：机器人弹奏 MIDI 音乐程序。需要给 CoCube 安装 MIDI 音乐模块。与 buzzer 程序类似，将 CoCube 放在音乐地图的不同琴键上，MIDI 音乐模块会发出对应音调；将 CoCube 放在音乐地图第一行的乐器区域时，可以切换音色；放在第二行的打击乐器区域时，可以用 A/B 按键触发对应的打击音效。

如果想退出当前程序，只需要再次按住 B 按键并连续按 4 次 A 按键，重新打开目录系统即可。

#### 3. 添加你的代码快照

下面用一个简单程序演示如何保存自己的代码快照。

首先，在 MicroBlocks IDE 的设置中开启“高级模式”。开启后，MicroBlocks 会显示与代码快照相关的功能，一些积木库也会开放新的积木。

![blocks](advanced_1.png)

然后，使用“LED 显示”库中的“显示图像”积木，以及高级模式下新增的“设置显示颜色”积木，绘制一个跳动的心形动画。

![blocks](codepng.png)

接着，点击“文件”菜单中的“snapshot code on board”，将快照命名为“heart”，然后点击“确定”。此时，当前程序就会被保存到 CoCube 芯片的文件系统中。

![blocks](snapshot1.png)
![blocks](snapshot2.png)

最后，务必断开 CoCube 与 MicroBlocks IDE 的连接，再打开目录系统。此时，你会在目录中看到刚刚保存的 heart 程序，之后就可以随时从目录中运行它。

#### 4. 删除你的代码快照

通常情况下，不需要主动删除已经保存的代码快照。如果确实需要删除，可以按下面的步骤操作：

1. 添加积木库：“其他”->“文件”。

2. 使用“文件名”积木查看文件系统中已经保存的内容。此时可以看到“heart.ucode”文件。

![ucode](ucode.png)

3. 使用“删除文件”积木删除“heart.ucode”文件。

![ucode](delate_ucode.png)

4. 再次使用“文件名”积木查看文件列表，确认“heart.ucode”文件已经被删除。断开 CoCube 与 MicroBlocks IDE 的连接后，再打开目录系统，也不会再看到 heart 程序。

#### 5. 注意事项

1. 在 MicroBlocks IDE 中升级固件时，文件系统会被恢复为出厂自带的代码快照。你自己保存的代码快照会丢失，如果需要，请务必提前备份。

2. 请在 CoCube 与 MicroBlocks IDE 断开连接后，再打开目录系统。连接状态下触发目录系统，可能会产生意料之外的问题。
